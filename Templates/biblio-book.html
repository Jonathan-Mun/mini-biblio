Description

Même un mauvais code peut fonctionner. Mais si le code n'est pas propre, il peut mettre à genoux une organisation de développement. Chaque année, d'innombrables heures et des ressources significatives sont perdues à cause d'un code mal écrit.

Dans ce livre, le légendaire expert en développement logiciel Robert C. Martin présente un paradigme révolutionnaire qui vous permettra de produire un meilleur code. Martin s'est associé à ses collègues de Object Mentor pour distiller leurs meilleures pratiques agiles et en extraire une approche de nettoyage du code.
